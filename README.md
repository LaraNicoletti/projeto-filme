# Sobre a atividade
Este repositório contém a entrega da atividade de Linguagem de Marcação apresentada pelos professores Raul Porto Lopes e André Luiz Denani. Possii o objetivo de por a prova os conhecimentos adquiridos sobre HTML fazendo um site informativo sobre um filme escolhido. A página foi desenvolvida como uma página informativa focada em apresentar a ficha técnica do filme Orgulho e Preconceito. A estrutura conta com o título da obra no topo, o cartaz oficial centralizado para identificação visual e uma seção explicativa com os principais dados técnicos da produção, como direção, país de origem, ano de lançamento, classificação, gênero e duração. Além disso, apresenta uma breve sinopse e um link que direciona o leitor a um site com mais informações.
